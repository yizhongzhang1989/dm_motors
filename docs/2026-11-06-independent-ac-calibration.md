# A/C 分离后的独立高速标定与验证

2026-11-06，操作者将 A（id=1）与 C（id=3）同轴连接拆开后完成测试。两轴各 11 轮正式实验、22 个正反向稳态窗口全部通过；最高档的全部窗口实测速度均超过 `4π = 12.56637 rad/s`。结束时 A、B、C 全部失能，双边控制器保持停止。

本次得到的是**当前驱动配置下的高速滑动阻力候选模型**，没有重新辨识惯量、静摩擦或整圈位置相关摩擦。`prediction_qualified=true`，完整标定的 `qualified=false`；原 `config/system_parameters.yaml` 未被覆盖。

## 测量方式

- 一次只使能 A 或 C，其他两轴失能；同时检查其位置没有跟随运动。双边控制器全程 IDLE，指令计数不增加。
- 被测轴原生 MIT `kp=10, kd=0.6, torque_ff=0`，指令频率 500 Hz。A 实际 RAM 速度带宽 100 Hz，C 为 40 Hz，每轮只读确认。
- 训练速度 `0.6 / 3 / 9 / 13.2 rad/s`，每档两个完整双向轮次；独立验证速度 `1.5 / 6 / 13.2 rad/s`，每档一轮。验证数据不参与拟合。
- 每轮轨迹约 3.25–5.77 秒，含加减速、折返及停稳，整轮结束后停机。通信发现等待在失能状态完成。
- 每个平台固定取中央 0.3 秒；以原始接收时间上的位置斜率核验实速，并交叉检查反馈速度、原始 CAN 指令与反馈。不能用指令值或瞬时峰值代替实速验收。
- A 先负转、C 先正转，直接利用原位置完成轨迹包络检查；没有归零、写 Flash 或改变坐标映射。

协议见 [independent_axis_speed_sweep.yaml](../config/independent_axis_speed_sweep.yaml)，运行及归档教程见 [独立轴高速滑动摩擦实验](calibration-independent-speed-sweep.md)。

## 结果

| 项目 | A / id1 | C / id3 |
|---|---:|---:|
| 正式轮数 / 有效窗口 | 11 / 22 | 11 / 22 |
| 最高档各窗口实速绝对值范围，rad/s | 13.18514–13.23076 | 13.18704–13.21675 |
| 高速双向平均上报阻力矩，Nm | 0.27364 | 0.34054 |
| 库仑项 Fc，Nm | 0.147053 | 0.109581 |
| 速度项 b，Nm/(rad/s) | 0.00966546 | 0.01712281 |
| 拟合偏置，Nm | −0.00230889 | −0.00407107 |
| 独立验证 RMSE，Nm | 0.008195 | 0.014162 |
| 独立验证最大窗口误差，Nm | 0.014267 | 0.022786 |

拟合式为 `τ = Fc·sign(v) + b·v + bias`。这里的力矩来自电机电流换算上报，并非独立轴端力矩传感器。偏置可能包含方向不对称或外部载荷，不应直接作为摩擦前馈偏置。候选参数及身份、速度域、验证指标保存在 [independent_axis_friction_20261106.yaml](../config/independent_axis_friction_20261106.yaml)，该文件不会自动启用补偿。

A 原配置只在约 ±0.4 rad/s 范围内合格，速度项接近零；在本次相同六个验证窗口上，其数学外推 RMSE 为 **0.090966 Nm**，新模型为 **0.008195 Nm**。这说明新增高速数据明显改善了高速预测，并不否定旧模型原有低速范围内的资格。C 之前没有独立标定基准。

C 的负向高速阻力略高于正向，最高档验证值也高于训练值。它仍通过预先冻结的 RMSE≤0.03 Nm、最大窗口误差≤0.06 Nm 门槛，但后续联轴测试应继续关注方向与温度差异。

## 对此前联轴阻力的解释

下表均为双向方向化均值；“旧联轴合计”是此前单边模式下 C 上报驱动力矩与 A 实际助力之和。

| 速度，rad/s | 本次独立 A+C，Nm | 此前联轴合计，Nm |
|---|---:|---:|
| 0.6 | 0.262680 | 0.258508 |
| 3 | 0.348300 | 0.343105 |
| 9 | 0.500354 | 0.502989 |
| 13.2 | 0.614177 | 0.616589 |

四档最大差约 0.00520 Nm。高速时，用本次独立损耗和旧 A 实际助力重构 C 的驱动力矩：

`0.273641 + 0.340536 − 0.019878 = 0.594299 Nm`

此前 C 实测约 0.596711 Nm。结果支持“两个电机自身阻力相加，而 A 的高速有效助力很小”的解释；不能在旧 C 驱动力矩上再加一次 C 自身阻力。A、C 的速度项也确实不同，今后仿真不必继续把两轴损耗假定为各占一半。

这仍是不同会话、不同温度及短窗口之间的对照；重新联轴后必须再次验证，不能把总量吻合当成独立力矩量程、惯量或全部摩擦机理已经认证。

## 自动流程、异常和停止证据

新增工具位于 [tools/physical_rig/independent](../tools/physical_rig/independent/README.md)。原生流支持轴号与先行方向；矩阵执行器保存计划、实际轮次、源码和输入哈希，并在每轮结束后审核实速、CAN、原始记录及全轴 STOP。

共保留 **7 次准备/启动诊断**，没有删除或计入正式训练：4 次在使能前发生只读能力握手超时；另 3 次已有使能请求，但尚未进入运动轨迹，分别暴露了使能源过渡判定、双边 IDLE 与双方失能标志混用、目标源尚未完成通信匹配的问题。后两类基线日志分别有 8 条和 41 条已发布目标；41 条目标未被驱动采用，原始 CAN 仅有中性指令。

修复后，目标发布进程先在失能状态稳定发现 8 秒，再使能；仍要求 80 ms 内确认实际目标源，并保持所有运动保护门槛。矩阵仅对“没有 ENABLE 请求、完整证据确认全轴已停机”的准备失败自动新建进程重试一次；任何使能后的异常或停止不明均中止。最后 C 高速验证实际验证了这条自动准备重试路径，成功后总清单确认两轴各 11 轮完整。

相关 173 项检查最终通过。首次汇总测试仅浏览器辅助测试缺少 Node 路径，补全已有运行时路径后该项重跑通过；原生发布还在隔离 DDS 域验证了轴号、镜像方向、位置包络和指令间隔。真机报告的 44 个正式窗口全部通过原始 CAN 与反馈审核。
